# Folder Slaid Modul 1

Sumber utama kandungan ialah [02-Kandungan-Slaid.md](../02-Kandungan-Slaid.md). Dokumen tersebut mengandungi 22 slaid, nota penyampai, cadangan visual dan interaksi.

## Hasil yang akan diletakkan di sini

- `Slaid-Modul-1-MPE.pptx` — fail kerja yang boleh disunting;
- `Slaid-Modul-1-MPE.pdf` — versi edaran atau sandaran;
- `Slaid-Modul-1-MPE-notes.pdf` — versi dengan nota penyampai jika diperlukan.

## Semakan pengeluaran

- [ ] Format 16:9 dan tema visual konsisten.
- [ ] Semua 22 slaid mempunyai nota penyampai.
- [ ] Masa aktiviti dan demo jelas.
- [ ] Tangkap layar menggunakan data rekaan.
- [ ] Kod QR dan pautan diuji.
- [ ] Fon dan kontras sesuai untuk bilik latihan.
- [ ] Versi PPTX dan PDF diperiksa secara visual.

Penambahbaikan reka bentuk boleh dibuat tanpa mengubah urutan pembelajaran atau jumlah masa dalam sumber kandungan.
