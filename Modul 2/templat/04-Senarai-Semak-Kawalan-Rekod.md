# Senarai Semak Kawalan Rekod

- [ ] Data dibenarkan untuk platform yang digunakan.
- [ ] Dokumen ditanda DRAF/SIMULASI.
- [ ] Fakta dibandingkan dengan sumber.
- [ ] Maklumat belum lengkap ditanda `[PERLU PENGESAHAN]`.
- [ ] Format dan bahasa disemak.
- [ ] Pegawai penyemak dan pelulus dikenal pasti.
- [ ] Nama fail mempunyai status, versi dan tarikh.
- [ ] Versi akhir dipindahkan ke sistem/fail rasmi.
- [ ] Sejarah chat tidak dianggap sebagai rekod rasmi.
