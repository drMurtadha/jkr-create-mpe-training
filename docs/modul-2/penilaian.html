Penilaian dan Exit Ticket Modul 2

Kuiz, rubrik hasil kumpulan dan refleksi individu.

Tinjauan awal

Minta peserta memilih satu jawapan bagi setiap pernyataan: Yakin / Kurang yakin / Tidak pasti.

  1. Saya boleh membezakan data yang selamat digunakan dalam latihan AI.
  2. Saya boleh membina prompt menggunakan K–T–B–F–S.
  3. Saya boleh mengesan fakta rekaan dalam draf AI.
  4. Saya tahu bahawa sejarah chat bukan repositori rekod rasmi.

Kuiz akhir

Pilih satu jawapan bagi setiap soalan. Markah dan jawapan hanya dipaparkan selepas semua soalan dijawab dan butang Hantar jawapan ditekan.

Rubrik hasil kumpulan

Kriteria 0 1 2
Ketepatan fakta Banyak fakta rekaan Ada isu kecil Semua boleh dijejak
Kelengkapan Unsur utama hilang Beberapa medan ditanda Lengkap atau ditanda untuk pengesahan
Format rasmi Tidak tersusun Sebahagian sesuai Struktur jelas dan sesuai
Bahasa Kabur/mengubah maksud Boleh difahami Ringkas, rasmi, makna kekal
Kawalan dan rekod Tiada kawalan Sebahagian kawalan Draf, versi, pelulus dan lokasi rekod jelas

Skor maksimum: 10. Hasil tidak boleh lulus jika terdapat fakta kritikal rekaan walaupun jumlah skor tinggi.

Exit ticket individu

Lengkapkan borang berikut sebelum meninggalkan sesi. Maklum balas akan disimpan dalam dokumen Google rasmi latihan selepas butang Hantar exit ticket ditekan.

Bukti penyempurnaan modul

Peserta menandakan bukti melalui kotak semak dalam exit ticket di atas. Tanda ini ialah pengisytiharan kendiri, bukan kelulusan fasilitator. Senarai yang ditanda dihantar bersama maklum balas untuk semakan.
