# Pek Template Antaramuka MPE

Pek ini menyediakan empat gaya CSS yang menggunakan struktur HTML yang sama.

1. Buka `contoh.html` dalam pelayar.
2. Tukar nilai `href` kepada salah satu fail CSS:
   - `tema-korporat.css`
   - `tema-makmal.css`
   - `tema-minimal.css`
   - `tema-dashboard.css`
3. Salin struktur atau CSS pilihan ke projek latihan anda.

Gunakan data rekaan sahaja. Uji kontras, papan kekunci dan paparan telefon sebelum penerbitan.
